# Stock Outlook Dashboard (local, VS Code)

พิมพ์ ticker อะไรก็ได้ กดวิเคราะห์ แล้วได้ข้อมูลราคาจริงจาก Yahoo Finance ทันที —
กราฟแท่งเทียน, โอกาสปิดบวก/ลบวันถัดไป, ช่วงราคาสูงสุด/ต่ำสุดที่คาด, และข่าวล่าสุด
ทำงานบนเครื่องคุณเอง (ต่างจากแดชบอร์ดเดิมที่เป็นเว็บเพจ ซึ่งดึงราคาสดเองไม่ได้)

## วิธีรันใน VS Code

1. เปิดโฟลเดอร์ `stock_outlook` นี้ใน VS Code
2. เปิด Terminal ใน VS Code (menu: Terminal → New Terminal) แล้วรันคำสั่งตามระบบปฏิบัติการ:

**macOS / Linux**
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

**Windows (PowerShell)**
```powershell
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

3. Streamlit จะเปิดเบราว์เซอร์อัตโนมัติที่ `http://localhost:8501` — พิมพ์ ticker (เช่น `MU`, `AAPL`, `NVDA`, หรือหุ้นไทยแบบ `PTT.BK`) แล้วกด "วิเคราะห์"

ครั้งต่อไปที่จะรัน แค่เปิด terminal แล้วรัน:
```bash
source venv/bin/activate   # Windows: venv\Scripts\Activate.ps1
streamlit run app.py
```

## ไฟล์ในโปรเจกต์

- `app.py` — หน้าเว็บ Streamlit (UI, กราฟ, การแสดงผล)
- `analysis.py` — การคำนวณสถิติทั้งหมด (ดึงข้อมูล, ความน่าจะเป็น, ช่วงราคา)
- `requirements.txt` — ไลบรารีที่ต้องติดตั้ง

## เปิดโหมดราคาเรียลไทม์จริง (ไม่ดีเลย์) ด้วย Alpaca — ไม่บังคับ

โดยดีฟอลต์ ราคา "เรียลไทม์" ในแอปนี้ดึงจาก Yahoo Finance ซึ่ง**ดีเลย์ ~15-20 นาที** ถ้าต้องการราคาจริงแบบไม่ดีเลย์
(เฉพาะหุ้นที่จดทะเบียนในสหรัฐฯ) สามารถต่อกับ [Alpaca](https://alpaca.markets) ซึ่งมีแผนฟรีที่ให้ข้อมูลเรียลไทม์จากตลาด IEX ได้:

1. สมัครบัญชีฟรีที่ https://alpaca.markets (เลือกบัญชี Paper/Basic — ไม่ต้องฝากเงินหรือเปิดบัญชีจริง)
2. ไปที่ Dashboard → API Keys → กด Generate New Key เพื่อได้ `API Key ID` และ `Secret Key`
3. คัดลอกไฟล์ `.streamlit/secrets.toml.example` เป็น `.streamlit/secrets.toml` แล้วใส่ค่าที่ได้:
   ```toml
   [alpaca]
   api_key_id = "..."
   secret_key = "..."
   ```
4. รันแอปใหม่ — ถ้าตั้งค่าถูกต้อง ส่วน "ราคาคาดการณ์แบบเรียลไทม์" จะขึ้น badge "🟢 เรียลไทม์ (Alpaca / IEX)" และอัปเดตทุก 5 วินาที
   แทนที่จะเป็น badge "ดีเลย์ ~15-20 นาที" ที่อัปเดตทุก 30 วินาที

**ห้าม commit ไฟล์ `.streamlit/secrets.toml` จริงเข้า git** (มีแค่ `.example` เป็นตัวอย่างเท่านั้น) และแผนฟรีของ Alpaca ครอบคลุมเฉพาะฝั่งตลาดหุ้นสหรัฐฯ
ถ้าไม่ตั้งค่าไฟล์นี้ แอปจะยังทำงานปกติโดยใช้ราคาดีเลย์จาก Yahoo Finance เหมือนเดิม

## วิธีคำนวณ (สรุป)

- **โอกาสปิดบวก/ลบวันถัดไป**: เฉลี่ยจาก 3 มุมมองของผลตอบแทนรายวัน (log return) ย้อนหลัง —
  (1) ความถี่จริงของวันบวกทั้งช่วงข้อมูล, (2) โมเดลการกระจายแบบปกติ (normal distribution) จากค่าเฉลี่ย/ส่วนเบี่ยงเบนมาตรฐานทั้งช่วง,
  (3) โมเดลเดียวกันแต่ใช้เฉพาะ 40 วันล่าสุด
- **ช่วงราคาคาดการณ์วันถัดไป**: ใช้สัดส่วน (High − ราคาปิดก่อนหน้า) และ (Low − ราคาปิดก่อนหน้า) ของ 40 วันทำการล่าสุด
  แล้วนำค่ามัธยฐาน (ช่วง "ปกติ") และเปอร์เซ็นไทล์ 10/90 (ช่วง "กว้าง") มาใช้กับราคาปิดล่าสุด
- **ATR(14)**: True Range เฉลี่ย 14 วัน — ตัวชี้วัดความผันผวนมาตรฐานที่นักเทรดใช้ทั่วไป
- **Volatility รายปี**: ส่วนเบี่ยงเบนมาตรฐานของผลตอบแทน 20 วันล่าสุด คูณ √252 แล้วแปลงเป็น %

ตรรกะทั้งหมดอยู่ใน `analysis.py` แก้ไข/ปรับสูตรได้ตามต้องการ

## ข้อจำกัด — สำคัญ

ตัวเลขทั้งหมดเป็น**การประมาณเชิงสถิติจากราคาย้อนหลัง**เท่านั้น ไม่ใช่การพยากรณ์ที่แม่นยำ
ไม่ได้รวมข่าวหรือเหตุการณ์ในอนาคตเข้าไปในสูตรคำนวณโดยตรง (ข่าวที่แสดงเป็นข้อมูลประกอบให้อ่านเองเท่านั้น)
และไม่ใช่คำแนะนำการลงทุน โปรดพิจารณาความเสี่ยงด้วยตนเองก่อนตัดสินใจ

หากข้อมูลดึงไม่ได้ (error ตอนกด "วิเคราะห์") มักเกิดจาก Yahoo Finance เปลี่ยนรูปแบบ API หรือ ticker พิมพ์ผิด —
ลองอัปเดตไลบรารีด้วย `pip install -U yfinance` แล้วรันใหม่
